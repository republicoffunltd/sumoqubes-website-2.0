03 WHAT IT IS

The core loop

Mobile-first, browser-native multiplayer, built in the spirit of Gang Beasts and Human Fall Flat — stripped down to something you can join from a room code and finish before the kettle boils.

01

Spawn

Four players drop radially onto a circular stadium platform.

02

Push & grab

Shove, dodge, or grab-and-throw opponents toward the edge.

03

Ring-out

Knock a cube off the platform and they're out — last one standing wins the round.

05 WHY ENTITY, SPECIFICALLY

We already build
on your stack

Entity is betting on WebGL/WebGPU, WebAssembly and WebRTC as the future of console-quality browser gaming. SumoQubes isn't a port — it's already built on exactly that foundation.

Rendering

React Three Fiber + Three.js

Real-time 3D rendering of the ring, the cubes, and their 20-bone squash-and-stretch rigs, running straight in WebGL.

→ Entity's WebGL / WebGPU pillar
Physics

Rapier (Rust → WASM)

Every push, grab and ring-out is real rigid-body physics, compiled to WebAssembly for near-native performance in-browser.

→ Entity's WebAssembly pillar
Multiplayer

Playroomkit / WebRTC

Room-code, host-authoritative multiplayer over WebRTC — four players in a match with nothing to install.

→ Entity's WebRTC pillar

07 DESIGNED TO SPREAD

Built for the clip,
not just the session

A ring-out is a complete, shareable moment — a few seconds of physics comedy with a clear winner. The character designs are deliberately simple and expressive: flat faces, bold silhouettes, no limbs to animate wrong. That's a roadmap strength for short-form platforms like TikTok, not a shipped feature today.

Access

A shared link or room code is the entire onboarding flow — the same zero-friction bar Entity is building the platform around.

Cross-device

Desktop keyboard input and mobile touch controls both drive the same physics build — one codebase, every screen.

08 BEYOND THE RING

VAS: the character
engine behind the game

Our Virtual Animation System is a separate real-time UE5 pipeline — face motion capture plus gamepad and MIDI-driven camera and lighting — that turns the roster into ongoing "kayfabe" video content for YouTube and TikTok, independent of the game's own codebase.

Status

Pipeline exists; webisode integration is scoped as post-sprint work, not yet shipping content.

Planned use

Opening feud: Horatio vs Punkie, then Horatio vs Jinx! — in-character rivalries driving the roster reveal.
